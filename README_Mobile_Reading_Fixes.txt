Наблюдатели Андромеды — мобильные исправления чтения

В этой версии обновлён index.html. Сюжетные модули Пролога и Глав 1–19,
четыре эпилога, сохранения, инвентарь, досье и Хронология Т2 взяты
из предыдущей полной сборки без изменений.

1. Типографика книги
   - Текст повествования, реплик и пролога выровнен по левому краю.
   - Принудительная расстановка переносов отключена.
   - word-spacing установлен в normal, а overflow-wrap и word-break
     возвращены к нормальному поведению, чтобы не разрывать слова на телефоне.

2. Кнопка Журнала
   - Кнопка #bLog закреплена в верхней панели с отдельным z-index и
     обработчиком onclick.
   - Журнал открывает три отдельные вкладки: «Записи», «Досье»,
     «Улики и тайны».
   - Исправлено ошибочное имя переменной itemainPanel в построении
     карты решений; карточки теперь добавляются в свой контейнер.
   - При закрытии модального окна свёрнутая панель действий не раскрывается
     автоматически.

3. Панель выбора и осмотров
   - После вывода сцены и входящего вызова выдерживается пауза 5 секунд.
   - Затем появляется компактная свёрнутая плашка «ВАШ ВЫБОР / ДЕЙСТВИЕ: ▼».
   - Список осмотров и вариантов ответа открывается только по нажатию игрока.
   - Таймеры ограниченного выбора запускаются после пятисекундной паузы.

4. Продолжение чтения
   - Новые абзацы добавляются в конец #chat через appendChild.
   - При нажатии «Читать дальше...» сохраняется текущий scrollTop.
   - Убрана автоматическая фокусировка и прокрутка к началу следующего фрагмента.
   - Для контейнера ленты отключено автоматическое scroll anchoring браузера.

Проверки
   - Все JS-модули глав и встроенный JavaScript index.html проверены через node --check.
   - Выполнена статическая проверка четырёх изменений и ключевых обработчиков.
   - Полноценное браузерное и мобильное тестирование в этой среде не завершено.
