ANDROMEDA — ГЛАВА 19, ЧАСТЬ 2
«Свобода выбора» · четыре финальных эпилога

Состав финальной главы в chapters/ch19.js:
- c19_01 — прибытие спасательного челнока и прощание с земными друзьями;
- c19_02 — момент окончательного выбора;
- c19_02a — развилка из четырёх вариантов судьбы;
- end_01 — «Жить среди людей»;
- end_02 — «Хранитель равновесия»;
- end_03 — «Посол двух галактик»;
- end_04 — «Мост между звёздами».

Каждый эпилог помечен isEnding: true, имеет уникальные endingCode / endingTitle,
полный заключительный текст, флаг открытия соответствующей концовки и действие
открытия Хронологии (Т2). Условие четвёртой концовки — наличие флага
ЛИОР_ВОЗРОЖДЁН; варианты II и III также сохраняют требования навыков Интуиция
и Эмпатия.

В движке выполнены необходимые согласования:
- названия в STORY_DATA.meta.endings синхронизированы с четырьмя эпилогами;
- обработчик финального экрана отображает кнопку «Открыть Хронологию» для
  authored action openTimeline. Обычные choices эпилогов не рендерились бы,
  поскольку isEnding направляет узел непосредственно на showFinal;
- узлы эпилогов сохраняют chapter: 20 и отображаются как отдельный том «Эпилог»,
  при этом загружаются из chapters/ch19.js через существующий путь модуля главы 19;
- заголовки сцен берутся из chapterTitle, в том числе для числового chapter;
- chronologyChapter относит end_01—end_04 к главе 20;
- удалены четыре устаревшие записи STORY_NODE_CHAPTER для прежних ID
  c19_02_earth, c19_02_bridge, c19_02_stars и c19_02_guardian: в финальном
  содержимом их заменяют end_01—end_04. Это необходимо для complete: true.
