НАБЛЮДАТЕЛИ АНДРОМЕДЫ — МОДУЛЬНАЯ СБОРКА

Содержимое:
- index.html — движок и интерфейс
- chapters/prologue.js — отдельный модуль пролога
- chapters/ch01.js ... chapters/ch19.js — данные сюжетных глав
- ch19.js также содержит четыре эпилога end_01 ... end_04
- start_local.bat — запуск локального HTTP-сервера на Windows

Запуск на Windows 10:
1. Распакуйте весь архив в одну папку. Не перемещайте папку chapters отдельно.
2. Дважды нажмите start_local.bat.
3. Игра откроется по адресу http://127.0.0.1:8765/index.html
4. Для остановки закройте минимизированное окно локального сервера.

Важно:
- Не открывайте index.html отдельно от папки chapters.
- Динамическая загрузка запускается при первом открытии пролога и при переходе в новую главу.
- При продолжении сохранённой игры движок загружает только модули глав, которые нужны для текущего и уже пройденного маршрута (это необходимо для восстановления старой ленты).
- В этой версии внедрена только модульная загрузка глав. Остальные две механики из описания «осмотр локаций, улики и звонки» в полученном фрагменте требований не раскрыты и не добавлены.
