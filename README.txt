ОБНОВЛЕНИЯ КНИЖНОЙ ПАГИНАЦИИ И ОФОРМЛЕНИЯ ДИАЛОГОВ

1. Книжная страница и общий объём
- В index.html используется базовая константа CHARS_PER_PAGE = 1600.
- Текущая страница считается строго по фактически прочитанному тексту: floor(st.charsRead / CHARS_PER_PAGE) + 1.
- Объём загруженной главы рассчитывается по всем текстовым сообщениям её сюжетных узлов, включая входящие вызовы; служебные разделители не учитываются.
- При каждой успешной загрузке модуля общий объём пересчитывается. Для уже загруженных глав используются фактические символы, а для ещё не загруженных — средний объём загруженных расширенных глав. Пока нет ни одной загруженной основной главы, используется базовая оценка 12 496 символов на главу; для Пролога — 23 323 символа.
- Книга оценивается как Пролог + 19 основных глав. В этой сборке полностью включены Пролог и Главы 1–9; Главы 10–19 остаются предварительно оценёнными до добавления их модулей. Общий объём автоматически уточняется при загрузке следующих модулей.
- Старое фиксированное значение 74 страницы удалено.

2. Оформление диалогов
- Реплики, начинающиеся с тире, распознаются отдельно от авторского повествования.
- Реплика Аэ́рхиса (включая формы имени в авторской ремарке) получает класс speech-hero: серебристо-голубая линия 3 px, мягкий синий полупрозрачный фон и голубая подсветка имени говорящего.
- Реплики других персонажей получают класс speech-npc: янтарная линия 2 px, мягкий тёплый фон и золотистая подсветка имени говорящего.
- Имя в авторской ремарке подсвечивается только тогда, когда оно определено как говорящий персонаж; упоминания других героев внутри реплики не превращаются в подпись говорящего.
