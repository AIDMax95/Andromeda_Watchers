ОБНОВЛЕНИЕ INDEX.HTML — 4 ТОЧЕЧНЫХ ИСПРАВЛЕНИЯ

1. Обложка очищена: убрана длинная аннотация и лишние вспомогательные элементы; оставлены метка, название, строка «Авторская книга-игра · 19 глав и 4 варианта эпилога», кнопки «НАЧАТЬ ИГРУ» и «ПРОДОЛЖИТЬ». Строка фактов отображается без курсива.
2. В карточках путей убраны подписи «· слова N»; удалена нижняя дублирующая кнопка продолжения.
3. Сохранение обновлено: вместе с состоянием сохраняются nodeId, chapterNum, лента chat, ресурсы, флаги, улики, очередь и положение прокрутки; позиция ленты сохраняется также при прокрутке.
4. Кнопка «ПРОДОЛЖИТЬ» проверяет сохранение. Без валидного сохранения она отключена и показывает «Нет сохранения». При продолжении сначала ожидается загрузка нужного модуля (включая модуль Пролога для p01_* / номера 0), затем восстанавливается лента, позиция чтения и элементы действий текущего узла. Незавершённый переход через pendingNodeId также завершается после загрузки модуля.
